# Nuvexa Global Transport — Brand Guide

> **Context:** the platform is finished and working. This job is a **re-skin**: name, logo, photos, admin password and
> tracking-ID prefix change; design, palette, fonts, layout and features stay. See `CLAUDE.md §0`.

**Approach:** the existing design system (`src/styles/tokens.css`) is kept as built. Only names, logo, photos and
identifiers change. If anything below conflicts with `CLAUDE.md §1`, CLAUDE.md wins.

## 1. Name usage

| Context | Use |
|---|---|
| Legal line, invoices, terms, footer copyright | **Nuvexa Global Transport Ltd** (`LEGAL_NAME`) |
| First mention on a page, titles, meta | **Nuvexa Global Transport** (`COMPANY`) |
| Repeated mentions, buttons, UI labels | **Nuvexa** (`COMPANY_SHORT`) |
| Never | "NUVEXA" in running text, "Nuvexa Transport", "Nuvexa Global" on its own, "NGT" as a name for the company (`NGT` / `ngt` is only the ID and internal code prefix) |

Copyright line: `© {currentYear} Nuvexa Global Transport Ltd. All rights reserved.` (year computed, not hard-coded).

## 2. Positioning

The positioning, pillars and page copy carry over unchanged from the existing site (`docs/CONTENT.md`), with the
company name swapped. Don't write new marketing copy as part of this job.

**Tagline:** **Faster • Safer • Further** (owner, 2026-10-03). Written as on the logo artwork, in text and code (`TAGLINE`); no closing full stop. The Home H1 headline keeps its two-line form *Faster, Safer, / Further.* It replaces the previous *Fast, Safe, Reliable.* in the Home H1, OG/Twitter
title and footer brand block.

## 3. Voice & tone (unchanged)

- Confident, clear, calm. Short sentences, active voice, concrete nouns.
- International (British) English: *organisation, colour, centre, licence*.
- Only real, verifiable numbers. "Tracking ID" everywhere on the public site; on documents "Tracking ID / Waybill No.".

## 7. Tracking ID and other identifiers

**Tracking ID (8 characters exactly):** `NGT` + 5 characters from the safe alphabet. Only the prefix changes.

```
Format:    NGT + [5 chars]           e.g. NGT7K2M9, NGTQ4X8T
Alphabet:  23456789ABCDEFGHJKLMNPQRSTUVWXYZ   (no 0/O, 1/I)
Regex:     ^NGT[2-9A-HJ-NP-Z]{5}$   (built from TRACKING_PREFIX)
Input:     trim, uppercase, strip spaces and dashes ("ngt 7k2-m9" → NGT7K2M9)
Pieces:    NGT7K2M9-01, NGT7K2M9-02 (a child label resolves to the parent)
```

The server allocates every ID (`server/trackingIds.ts`, uniqueness check + retry). Logic stays as built.

**Other references:**

| Kind | Format | Example |
|---|---|---|
| Seal | `NGT-SL-######` | NGT-SL-892401 |
| Support / contact ticket | `NGT-TKT-######` | NGT-TKT-418230 |
| Invoice | `NGT-INV-######` | NGT-INV-004091 |
| Placeholder before an ID is assigned | `NGT·····` | |

**Style:** real operations with real people: aircraft loading, container terminals, warehouses, couriers handing over
parcels, customs paperwork, vehicles. Natural light, diverse global settings. **No other company's logo** visible on
vehicles, uniforms or buildings, and nothing from the previous brand.
